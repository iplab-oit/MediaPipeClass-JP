# MediaPipe Class 日本語版ガイド
- 対応バージョン: mediapipe 1.0.0 以降
- これはオリジナルの [MediaPipeClass](https://github.com/ipbl-oit-siit/MediaPipeClass)(英語版・iPBL向け)を、日本語話者の学生が迷わず使えるように再構成した公式ガイドです。
- クラスファイル・サンプルコード・サンプル画像はこのフォルダの[code/](code/)にすべて同梱されており、このフォルダ単体で動作します。
- 各ページ冒頭の「英語の元ページ」リンクのみ、英語版リポジトリ`MediaPipeClass`を別途お手元にクローン/配置している場合にだけ開けます(必須ではありません。より詳しい応用例を見たいときの追加リンクです)。

---
## この後、何をすればいいか(まずここだけ読めばOK)
1. [01_セットアップ](01_セットアップ.md) を読んで、必要なライブラリを準備する。
2. 下の「機能一覧」から使いたい機能を1つ選ぶ。
3. 対応するページ(例: 手を使いたいなら [03_ハンド](03_ハンド.md))を開き、「動かしてみる」のコードをコピーして実行する。
4. 動いたら、同じページの「もう少し詳しく」を読む。
5. 複数のクラスに共通する技(座標の取り方、重心計算、角度計算など)は [02_共通の使い方](02_共通の使い方.md) にまとめてあるので、慣れてきたら読む。
6. 自分の物体・ジェスチャーを認識させたくなったら [10_自分のモデルで学習する](10_自分のモデルで学習する.md) を読む。

## 注意
- 各ページのサンプルコードは、[code/](code/)フォルダにある `MediapipeXxx.py` ファイルと同じフォルダに置いて実行してください。
- 画像を使うサンプル(`_image`が付くもの)は `code/img/standard/` の画像を使います(このフォルダにすでに含まれています)。
- より詳しい・より多くの応用例(英語)を見たい場合は、各ページ冒頭にある「英語の元ページ」リンクから参照してください。ただしこちらは英語版リポジトリ`MediaPipeClass`が別途お手元にある場合のみ開けます。
